# Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful, harassment-free experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept feedback quickly when impact differs from intent.
- Keep discussions focused on improving the project.
- Report security or sensitive issues privately when possible.

## Unacceptable Behavior

- Harassment, discrimination, or hateful conduct.
- Personal attacks, threats, or intimidation.
- Publishing private information without permission.
- Deliberate disruption, spam, or bad-faith behavior.

## Scope

This Code of Conduct applies to issues, pull requests, discussions, documentation, and any other official project spaces.

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that violate this Code of Conduct.

If you need to report a serious incident, contact the maintainer through GitHub without posting sensitive details publicly.
