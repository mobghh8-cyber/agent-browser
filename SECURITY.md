# Security Policy

## Reporting a Vulnerability

Please do not publish exploit details, secrets, or proof-of-concept attack steps in public issues.

Use GitHub private vulnerability reporting when available. If that is not available for this repository, contact the maintainer through GitHub first and share only the minimum details needed to reproduce the issue safely.

## What to Include

- Affected version, branch, or commit if known
- Clear reproduction steps
- Impact assessment
- Suggested mitigation, if you have one

## Response Goal

Best effort review will happen as soon as practical, with priority based on severity and exploitability.
